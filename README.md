# Abstraccion

## Introducción

\
Este trabajo es para la materia **abstracción y uso de datos** es una práctica de programación orientada a la estructuración y manipulación eficiente de datos. Su objetivo principal es aprender a:

A través de estas prácticas, se desarrollan habilidades fundamentales para resolver problemas computacionales complejos de manera ordenada y eficiente.

En este proyecto se trabajaron los siguientes temas
- Estructuras de tipo **LIFO** (Pilas) y **FIFO** (Colas) y Listas

- Metodos de Ordenamiento como: **Quick Sort Merge Sort y Bubble sort**
